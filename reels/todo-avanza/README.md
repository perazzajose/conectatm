# Reel "Todo avanza" (HyperFrames)

Video vertical de 22,4 s que promociona los talleres de /aprende.

- `compositions/hook.html`: "Todo avanza." con las tres tarjetas (IA, estafas, autos).
- `compositions/ia.html`: "La IA avanza.", un chat genérico que escribe un aviso para un almacén.
- `compositions/estafa.html`: "Las estafas también.", un mensaje de estafa típico con sus señales de alerta y el sello.
- `compositions/auto.html`: "La tecnología también.", un auto volador de diseño propio, sin marca.
- `compositions/end.html`: "¿Y vos?", los tres talleres de la web, link y logo.

Los textos se cambian directamente en cada archivo de `compositions/`. Vista previa: `npm run dev`. MP4: `npm run render`.
