# Reel Pix para turistas (HyperFrames)

Video vertical de 21,7 s, marca azul. Para comercios del Chuy y la frontera que les venden a brasileños.

- `compositions/pix.html`: gancho (de los 8 POS del comparador, solo 2 aceptan Pix: Handy y Fiserv), las 4 preguntas del recomendador real con sus toques, el resultado y el acercamiento a "Preguntales... las comisiones".
- `compositions/end.html`: cierre con captura de /negocios/pos, logo, link y WhatsApp.
- `assets/t*.png`, `q*.png`, `resultado.png`, `pos-top.png`: capturas reales del sitio local (11/11/2026, viewport 400 px a 2,7x). Si cambian los datos de `src/data/posProveedores.js`, volver a capturar y revisar el "2 de 8".

Recursos con motivo: el filtro que apaga 6 de 8 (lo que hace la web), la página que se corre hasta cada pregunta y el resultado que aparece abajo, como en el sitio.

Vista previa: `npm run dev`. MP4: `npm run render`.
