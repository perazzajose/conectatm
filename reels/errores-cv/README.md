# Reel "5 errores del CV" (HyperFrames)

Video vertical de 26,2 s, paleta lila de la web. Una lupa recorre un CV plano inventado (Lucía Fernández, datos ficticios) y marca cinco errores: nombre del archivo, foto enojada, mail poco serio, faltas de ortografía y experiencia desordenada. Después el CV se arregla solo y cierra con "Te lo reviso gratis", WhatsApp y el sello.

- `compositions/revisar.html`: el CV, la lupa (una copia ampliada del CV dentro de un círculo) y los títulos de cada error. Los puntos que recorre la lupa están en `P`.
- `compositions/end.html` y `compositions/sello.html`: cierre y sello GRATIS.

Vista previa: `npm run dev`. MP4: `npm run render`.
