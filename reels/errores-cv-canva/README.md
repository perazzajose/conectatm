# Reel "5 errores del CV", estilo de los diseños de Canva

Misma animación que `reels/errores-cv`, con el estilo de los reels que José hizo en Canva: fondo morado #5C3D8A, títulos en mayúscula (Oswald), etiquetas en píldora azul noche #171D58, cintas lila #C4A8E8 con "GRATIS", puntos decorativos, @conectatumundo y botón verde de WhatsApp en el cierre.

Vista previa: `npm run dev`. MP4: `npm run render`.
