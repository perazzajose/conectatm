# Reel CV gratis para la Expo de Chuy (HyperFrames)

Video vertical de 18 s con la paleta de la web (buganvilia #8E3A86 sobre lila suave #F4E8F2, IBM Plex Sans, bloques rectos).

- `compositions/hook.html`: "¿No tenés CV para la Expo?" con un CV terminado de ejemplo.
- `compositions/armar.html`: "Lo armamos juntos.", el CV se arma por partes y aparece el real con "Listo en PDF".
- `compositions/gratis.html`: "Totalmente gratis." con tres beneficios.
- `compositions/end.html`: "Escribime y lo hacemos.", WhatsApp, logo y web.

El CV es el ejemplo del generador (Lucía Fernández, datos ficticios). Vista previa: `npm run dev`. MP4: `npm run render`.
